# Upstream and licence status

This repo was started from a copy of [MIRA-science/MIRA-extraction](https://github.com/MIRA-science/MIRA-extraction) (SciOS), taken at upstream commit `8d98e35`.

**Licence:** upstream's README says "License: TBD" and the repo has no LICENSE file. The maintainer of this repo (Thane Campbell, Deep Science Ventures) reports having the creators' approval to reuse the code. **Until upstream publishes a licence, or the creators confirm in writing, treat this repo as private/unreleased and do not redistribute it.** When a licence lands upstream, copy it here and update this file.

Third-party material that does carry a licence: the MIRA schema ([MIRA-science/schema](https://github.com/MIRA-science/schema), Apache-2.0) vendored for validation under `schema/`.
